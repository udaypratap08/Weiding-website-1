# Premium Wedding Invitation Website 💍

A premium, mobile-first digital wedding invitation made with:

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Responsive design
- Scroll reveal animations
- Countdown timer
- Gallery lightbox
- RSVP demo form
- Share button
- Music control

## Run

Open `index.html` in VS Code using Live Server.

## Customize

Open `index.html` and change:

- Couple names
- Wedding date
- Event names/times
- Venue
- Google Maps link

## Photos

The demo uses online Unsplash images. For a real client/project:

1. Put your own photos in `/images`
2. Replace the image URLs in `index.html`
3. Keep image sizes optimized for fast loading

## Music

Put your own copyright-safe music here:

`music/wedding.mp3`

The music button is already connected.

## Real RSVP

The current RSVP is frontend-only. For a complete full-stack version, connect it to:

Frontend → Node.js/Express → MongoDB

Then add an admin dashboard to see guest responses.

## Deployment

This static version can be deployed directly on:

- Vercel
- Netlify
- GitHub Pages

For a full-stack version, deploy the frontend and backend separately or use a suitable full-stack hosting setup.
